# Indexation Sémantique & Embeddings — Luxeflexia

Cet espace est configuré pour accueillir les représentations vectorielles ou les matrices de similarité AST du projet.
Dans le cadre de l'architecture Graphify déterministe, les index relationnels dans `graphify/indexes/` assurent une recherche en temps constant O(1) sans dépendre d'un magasin vectoriel externe.
